# ジグポン / ZigPop（テスト版）

1タップで矢印の連鎖が盤を走るパズルです。毎日みんな同じ盤に挑戦できます。
ブラウザで開くだけで遊べます（登録・通信なし。記録は端末内にだけ保存されます）。

A one-tap chain puzzle with a daily board everyone shares. Plays in the browser; no sign-up, records stay on your device.
